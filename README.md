# Obsidian Progress System

An Obsidian vault template for daily planning, habit tracking, weekly reviews, and long-term progress visibility.

The system is built around simple daily notes, reusable templates, and a Dataview-powered dashboard that turns daily inputs into visible progress over time.

## Features

- Daily reset template for planning and reflection
- Must-win task system for choosing the top three priorities
- Progress fields for study, projects, health, languages, and long-term goals
- Weekly review template for reflection and planning
- Dataview dashboard for recent progress, totals, and average score
- Minimal Obsidian settings for Daily Notes and Templates

## Requirements

- [Obsidian](https://obsidian.md/)
- Dataview community plugin

## How To Use

1. Open this folder as an Obsidian vault.
2. Enable community plugins in Obsidian.
3. Install and enable Dataview.
4. Use `Templates/Daily Checklist Template.md` for each daily note.
5. Fill in the `Daily Progress Input` fields every day.
6. Open `Progress Dashboard.md` to review progress over time.

## Main Idea

The system is intentionally lightweight. It does not require a perfect day or a complicated productivity method. It asks for honest daily input, a few clear priorities, and enough reflection to keep momentum visible.
